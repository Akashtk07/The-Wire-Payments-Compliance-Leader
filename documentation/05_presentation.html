Hash Chain Algorithm

  SHA256(prev_hash)

# Tamper any entry →
# all subsequent hashes invalid
# → tamper immediately detectable
Entry 1 → hash_1 = "abc123..."
Entry 2 + hash_1 → hash_2 = "def456..."
Entry 3 + hash_2 → hash_3 = "ghi789..."

Security Controls

  • IBAN masking via regex before any write
  • Account number masking (8+ digits → [MASKED])
  • API keys shown as preview only (first 8 + last 4)
  • Daily NDJSON rotation for easy auditing
  • Async lock prevents concurrent write corruption
  • Global error handler — no stack traces to clients
  • CORS restricted to frontend origin only

Engineering Excellence

Key Design Decisions

🚀 Zero-Dep AI Calls

All LLM providers called via pure httpx REST. No grpcio, no google-generativeai SDK. Eliminates Windows C++ compilation failures.

⚡ Async-First

async/await throughout — aiofiles, httpx.AsyncClient, asyncio.Lock. Single uvicorn worker handles hundreds of concurrent LLM calls.

🦥 Lazy Loading

ChromaDB + sentence-transformers imported only on first document operation. Server starts in ~2 seconds even without ML packages installed.

🔌 React Portal

LLMConfigPanel uses createPortal() to render at document.body level — escapes sidebar's stacking context for true full-viewport modal.

📦 Built-in dotenv

Custom _load_dotenv() pre-loads .env into os.environ before pydantic-settings — bypasses Windows path resolution issues.

♻️ Hot-Swap Config

llm_config_store singleton — update provider/model/key via REST API. llm_router always reads live state. No restart needed.

Non-Functional Requirements

  • Fully async — no blocking I/O in hot path
  • 3-attempt retry with exponential backoff
  • 60s timeout per LLM call
  • Graceful fallback on LLM failure
  • aiofiles for non-blocking audit writes
  • asyncio.Lock — race-condition-free log writes

Scalability Path

  • Stateless API → horizontal scale with load balancer
  • Replace NDJSON with WORM S3 for production
  • Replace embedded ChromaDB with Pinecone/Weaviate
  • gunicorn + UvicornWorker for multi-process
  • JWT auth layer already scaffolded in config
  • nginx reverse proxy for HTTPS + SSL termination
